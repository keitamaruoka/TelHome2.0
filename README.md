# テレフォンホーム（TelHome）

フィーチャーフォン風の大きなタイルで使える Android ランチャーです。

- **ホーム**：電話・メール・電話帳の大タイル、自由に割り当てられる小タイル12枠（4列×3段）、Firefox検索バー、MENUボタン
- **右へスワイプ**：着信履歴（番号ごとに件数をまとめて表示、不在着信は赤）
- **左へスワイプ**：発信履歴
- **MENU**：メール / インターネット / アプリ一覧 / カメラ / ギャラリー / 便利ツール（電卓・アラーム・ライト）/ 電話機能 / 本体設定 / 地図 / スケジュール / プロフィール / ドキュメントビューワー
- **アプリ一覧**：アイコンを長押しで「移動する」「フォルダに入れる」「非表示にする」。右上のボタンでフォルダ作成（名前付き）と非表示アプリの再表示

小タイルは **長押し** で、標準機能か任意のアプリに割り当てを変更できます（空き枠はタップでも変更できます）。

## APKの作り方

### A. GitHub Actions（PCに何も入れなくてよい）
1. GitHubで新しいリポジトリを作り、このフォルダの中身を丸ごとアップロード（`.github` フォルダも含める）
2. リポジトリの **Actions** タブで「Build APK」が自動で走ります（5〜8分）
3. 完了したら実行結果ページ下部の **Artifacts** から `TelHome-apk` をダウンロード → zip内の `app-release.apk` を端末へ

### B. Android Studio
1. Android Studio でこのフォルダを開く（初回は依存ライブラリのダウンロードに時間がかかります）
2. メニュー **Build > Build App Bundle(s) / APK(s) > Build APK(s)**
3. `app/build/outputs/apk/` に APK ができます

## インストールと設定
1. 端末で「提供元不明のアプリ」のインストールを許可して APK を開く
2. ホームボタンを押して「テレフォンホーム」を選び「常時」を選択
   （あとから変える場合：設定 > アプリ > デフォルトのアプリ > ホームアプリ）
3. 履歴画面で「許可する」をタップし、通話履歴と電話の権限を許可

## メモ
- 履歴の「📞」ボタンはそのまま発信、行のタップはダイヤル画面（番号確認）を開きます
- 通話履歴の権限を使うため、このままでは Google Play には公開できません（個人・社内配布向け）
- APK はデバッグ用の鍵で署名しています。配布する場合は自前の署名鍵に変更してください
- 動作対象：Android 8.0 以上
